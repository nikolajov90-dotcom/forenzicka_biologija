Forenzička biologija — Streamlit aplikacija

Pokretanje lokalno:
1. Instalirajte Python 3.10 ili noviji.
2. Otvorite terminal u folderu aplikacije.
3. Instalirajte zavisnost:
   pip install -r requirements.txt
4. Pokrenite:
   streamlit run app.py

Aplikacija sadrži dva taba:
- Prvo predavanje — Forenzička genetika (sažetak + 20 pitanja)
- Prve vežbe — Mesto zločina i tragovi (sažetak + 20 pitanja)

Pitanja i sažeci sastavljeni su prema dostavljenim prezentacijama i udžbeniku
Forenzička biologija (Čakar i Marjanović, ur., 2023), posebno poglavlju 3
za uvod u forenzičku genetiku.
